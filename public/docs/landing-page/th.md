| คุณสมบัติ | Free | Pro |
|---------|:----:|:---:|
| การค้นหาแบบรวม (แอป, ผู้ติดต่อ, ไฟล์, การตั้งค่า) | ✓ | ✓ |
| อัลกอริทึมการค้นหาทั้งหมด (คำนำหน้า, ฟัซซี่, เสียง) | ✓ | ✓ |

| ค้นหา Google Drive | ✓ | ✓ |
| ค้นหา Dropbox & OneDrive | — | ✓ |
| การค้นหาเนื้อหาไฟล์ (ข้อความเต็ม) | — | ✓ |
