# Free vs Pro — UniSearch

## 검색

| 기능 | Free | Pro |
|---------|:----:|:---:|
| 통합 검색 (앱, 연락처, 파일, 설정) | ✓ | ✓ |
| 모든 검색 알고리즘 (접두사, 퍼지, 음성) | ✓ | ✓ |
| 내장 계산기 | ✓ | ✓ |
| Google Drive 검색 | ✓ | ✓ |
| Dropbox & OneDrive 검색 | — | ✓ |
| 파일 내용 검색 (전체 텍스트) | — | ✓ |

## 사용자 정의

| 기능 | Free | Pro |
|---------|:----:|:---:|
| 테마 | 2개 테마 | 5개 테마 + 커스텀 크리에이터 |
| 색상 | 기본 | 54개 사용자 정의 포인트 |
| 애니메이션 | 기본 | 11가지 유형 + 속도 제어 |
| 레이아웃 및 기하학 | 기본 | 완전한 제어 (반경, 패딩, 테두리) |
| 아이콘 팩 | 시스템만 | + 외부 팩 |
| 배경화면 | 시스템 | 커스텀 색상 + 블러 |
